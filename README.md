# Machine Learning Projects

## About This Repository

Welcome to my Machine Learning Projects repository! This repository contains hands-on projects developed using Python and machine learning techniques. These projects demonstrate my understanding of data preprocessing, exploratory data analysis (EDA), feature engineering, model building, and model evaluation.

## Technologies & Tools

- **Programming Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- **Environment:** Jupyter Notebook
- **Core Concepts:** Data Cleaning, EDA, Feature Engineering, Regression, Classification, Model Evaluation

## Projects

### 1. Car Price Prediction
Builds a machine learning regression model to estimate vehicle prices based on available car features.

### 2. Credit Card Fraud Detection
Explores classification techniques to identify potentially fraudulent credit card transactions.

### 3. Diabetes Prediction
Uses health-related data to build a classification model for predicting diabetes risk.

### 4. Gold Price Prediction
Analyzes historical gold price data and explores regression techniques for price prediction.

### 5. Heart Disease Prediction
Uses patient health indicators to build a classification model for heart disease prediction.

### 6. Heart-2
An additional notebook exploring heart-related data analysis and prediction. Refer to the notebook for its specific implementation.

### 7. House Price Prediction
Builds a regression model to estimate property prices based on housing features.

### 8. Loan Prediction
Explores applicant data and classification techniques to predict loan approval outcomes.

### 9. Rock vs Mine Classification
Uses sonar signal data to classify samples as rocks or mines.

4. Open a notebook and run the cells in sequence.
5. Ensure the required datasets are available in the expected paths.
